# Jarvis Offline

Отдельный Android-проект «Джарвис», не связанный с предыдущими приложениями.

## Выбранная голосовая модель
Используется Piper `ru_RU-dmitri-medium`, преобразованная для движка sherpa-onnx. Это русский мужской нейросетевой TTS, работающий локально после подключения Android runtime. Размер исходной ONNX-модели около 63 МБ; вспомогательные файлы и runtime добавляют объём, но остаются намного ниже лимита 3–6 ГБ.

- Карточка исходной модели: https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/dmitri/medium
- Документация конвертированной модели: https://k2-fsa.github.io/sherpa/onnx/tts/all/Russian/vits-piper-ru_RU-dmitri-medium.html
- Runtime и исходники Android: https://github.com/k2-fsa/sherpa-onnx/tree/master/android

## GitHub Actions artifacts
После успешного запуска workflow `Android APK and offline voice bundle` в Actions появятся два отдельных артефакта:
- `jarvis-debug-apk`: debug APK приложения.
- `jarvis-russian-male-voice`: ZIP с данными голосовой модели и инструкцией интеграции.

ZIP — это данные модели, не самостоятельный исполняемый движок. Для использования голоса внутри приложения необходимо подключить sherpa-onnx Android API/JNI и вызвать синтез с файлами модели. Текущий прототип приложения пока использует системный Android TTS и ещё не подключает эту модель.

## Текущее состояние приложения
- Android-приложение на Kotlin.
- В код подключён sherpa-onnx Android runtime и синтез речи через Piper dmitri medium.
- Workflow скачивает модель во время CI, включает её в APK и отдельно собирает ZIP голосовых данных.
- Базовые команды: открыть камеру, открыть музыку, открыть набор номера.
- Голосовой ввод пока использует Android SpeechRecognizer с флагом prefer-offline. Это не гарантирует полностью локальное распознавание на каждом устройстве.
- В манифесте нет разрешения INTERNET.

## Проверка сборки
Изменения в GitHub отправлены, но успешный запуск CI и тест на реальном телефоне ещё не подтверждены. Пока артефакты не появятся в Actions, APK и ZIP нельзя считать проверенными.

## Честные ограничения
Собственная модель распознавания речи пока не включена. Системное распознавание Android может не работать без установленного языкового пакета. Piper medium даёт один мужской голос, но не гарантирует реалистичный смех, эмоциональные переключения или все интонации. Это отдельные задачи синтеза и просодии, которые требуют дополнительной модели или обработки. APK и голосовой ZIP не считать проверенными, пока GitHub Actions не завершится успешно и результат не будет протестирован на реальном Android-устройстве.
