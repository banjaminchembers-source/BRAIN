# Jarvis Offline

Отдельный Android-проект «Джарвис», не связанный с предыдущими приложениями.

## Основа проекта
- Android-приложение на Kotlin.
- Голосовой ввод с предпочтением локального распознавания Android.
- Локальная озвучка через установленный Android TTS-движок.
- Базовые команды: открыть камеру, открыть музыку, открыть набор номера.
- GitHub Actions для сборки debug APK.
- Нет разрешения INTERNET: приложение само не выполняет сетевых запросов.

## Честный статус
Это стартовая основа, а не законченный автономный голосовой пакет. Отдельная выразительная русская TTS-модель и отдельная модель распознавания речи пока не включены. Системный TTS использует голос, установленный на устройстве; системное распознавание может потребовать отдельного офлайн-пакета. Для гарантированного офлайн-голоса нужно выбрать совместимую модель, проверить лицензию и Android runtime, затем подключить и протестировать файлы модели. Исходный код сам по себе не создаёт обученную нейросеть и не содержит 3–6 ГБ голосовых данных.

## Сборка
GitHub Actions собирает debug APK после push в main. APK публикуется как artifact с именем jarvis-debug-apk в разделе Actions.

## Проверка
Установить APK, установить офлайн-пакеты русского распознавания и TTS в Android, включить авиарежим и проверить команды. Если локальное распознавание недоступно, приложение покажет ошибку. До подключения отдельной TTS-модели приложение нельзя считать полностью автономным по голосу.
